Dashboard needs which pages?

Select all that apply — click each page you want

1

Overview / Dashboard

At-a-glance cluster health: running jobs, worker status, queue depth, recent failures

2

Mirrors (Jobs)

All mirror repos in one table/list: status, last sync, next sync, trigger button. Click into detail view with action history + logs.

3

Workers

All registered workers: online/offline, labels, running actions, heartbeat. Remove offline workers.

4

Queue

Dispatch queue: pause/resume, reorder, set concurrency, remove entries.

5

Recent Actions

Cross-repo action history with filtering. Click to see logs.

6

Repo Configs

Raw config viewer: image, volumes, command, interval, node affinity. Read-only.
